# Data sample

`Unfallorte2024_sample.csv` — a random sample of **1,000 rows** (seed 42) from
the 2024 Unfallatlas file (`Unfallorte2024_EPSG25832_CSV.zip`, 268,519 rows),
kept here so the analysis is explorable without downloading the full ~96 MB
of raw yearly files. Columns are the raw portal columns, unchanged
(semicolon-separated source file; this sample is comma-separated).

Full data: download the nine yearly zips from
https://unfallatlas.statistikportal.de/ into `data/` and run `../prep.py`.
